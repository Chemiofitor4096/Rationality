### 1.3 基础设施缺口

- **零 config**：`RecipeTargets` 是静态 `HashSet`，无 `ModConfigSpec`；数值（污染 24000 刻、黑液 250mB 等）全硬编码

## 3. 设计判据（从反馈倒推的原则）

1. **无孤儿**：任何中间物至少一个下游（①⑦⑫ 的共同诉求，也是 06 F5 的验收线）
2. **反应可解释**：产物与原料在化学/工艺上能讲通（①"有明确含义的反应"）
3. **惩罚可配置**：污染/腐蚀类硬核机制必须能关（⑥ 的反调 + ⑩⑭）
4. **工业批产优于手工**：批量路径要"更快更省"，而不是更繁琐（⑨）
5. **广度优先接现有链**：优先做能接上造纸/碱循环的化学（④⑤⑬），拒绝纯新增孤岛
6. **不为化学而化学**：不做纯套娃、不做 GT 式矿物全处理（⑨作者反应 + ⑫）

## 5. 重构方案

### 5.1 黑液：从"污染废液"到"三出口化学品枢纽"（P0 设计，最高优先）

> **已定（2026-09-19）：先做方向 B，不做本节的完整枢纽。** 具体落地：恢复 `lye_from_concentrated_black_liquor`（苛化回碱）、浓缩黑液恢复**安全形态**（不污染）、骨粉改为**原版产量 ×3**并**移出 `alkaline` 标签**（消除"黑液造骨粉 + 污染禁骨粉"和"骨粉绕开碱线"两处矛盾）。
> **2026-09-25 追加拍板**：① **黑液提硫不成立**——现行蒸煮配料（碱性物 + 水）没有硫源，黑液里无硫可提，本节的"硫出口"作废；若将来重提，正确路径是先让蒸煮吃硫（硫酸盐法的 Na2S/芒硝添加），而不是从无硫黑液里变出硫。② **硫酸/硝酸等待气体处理模组联动**后立项（作者已有候选模组），v1 不做酸配方。③ **硝化棉线整体改由"棉花"模组联动承接**（棉 → 硝化棉），与 CBC 的 `can_be_nitrated` 标签衔接。④ **硝化甘油概念保留**，跟随酸系统落地。本节其余内容仍为提案。

**问题回顾**（代码核实）：当前黑液只有一个出口 `bone_meal`，而黑液造成的污染恰好禁用骨粉（`CropGrowHandler.bonemeal` 取消 `BonemealEvent`）——社区指出的"意义不明"确实成立；WIP 又把唯一的回收配方（苛化）删掉、让浓缩液也污染，形成纯孤儿。

**定位建议**：黑液 = 木质素（有机物）+ 碱 + 水 + 硫化物。按成分给三条语义出口，全部沿用 Create 现成机器（混合机/加热），不新增方块：

| 出口 | 反应 | 产物 | 对应反馈 |
|---|---|---|---|
| **碱** | 浓缩（加热，250→100mB）→ 苛化（+生石灰） | 碱液 100mB + 碳酸钙（熔烧回生石灰） | ①"有明确含义的反应"、⑤ 前身 |
| **硫** | ❌ **已否决（2026-09-25）**：现行蒸煮配料无硫源，"黑液提硫"化学前提不成立 | — | 若引入含硫蒸煮助剂（硫酸盐法）再议 |
| **有机物** | 黑液 + 骨头/腐殖/食物残渣 → 发酵 | 沼气/甲烷（加入 `c:fuel` 标签即可被 CDG 引擎燃烧，实现前实测）+ 骨粉 | ⑦"生物防治产沼气" |
| **固体杂质** | 岩浆 + 黑液 → 煤矸石（**已实现**）→ 粉碎 | 煤矸石粉 → 燃料 / 洗选 → 明矾·铝（可选，克制） | ①"转成物品形式的杂质" |

**配套修改**：
1. **恢复苛化配方**并把数值做实：目前 F1 的"10% 回补"是靠"浓缩虚减体积"凑出来的象征性数字。建议改为**成分标注制**：黑液 250mB 明确含碱 X、含水 Y、含硫 Z（写进 JEI/文档），苛化回收 = 碱成分的 N%；数字此后可调，语义先立住。
2. **切断骨粉悖论**：把污染对骨粉的"全禁"降级为"施肥效果打折"（并入 F3 污染分级），或把骨粉配方改为不依赖黑液；两者选一即可，别同时保留矛盾。
3. **给煤矸石粉下游**：现状 100 tick 燃烧值 + 无工艺用途 = 新的孤儿（违反判据 1）。最小落地：煤矸石粉 → 混合（洗选）→ 硫/明矾副产，或直接作为"劣质燃料"给蒸汽/熔炉但数值要符合"劣质"（100 tick 太低，建议 200~400 tick 并写明定位）。
4. **文档化**岩浆反应（03/02 目前没有这条）。

**待你决定**：黑液最终定位是 (a) 待处理废液（净化为主，污染重）还是 (b) 待提取原料（资源化为主）？社区共识与作者回应都指向 (b)，本方案按 (b) 展开。

### 5.3 无机广度：盐与氯碱（P1，一次满足气体/盐/氯/漂白）

链路：**盐 → 碱 + 氯 + 氢 → 漂白粉 → 漂白纸浆 → 特种纸**

- **盐来源**（二选一或都做）：
  a. 黑液熔烧 → 苏打灰/碱灰（钠盐回收，接 §5.1 的固体出口，无需世界生成）
  b. 岩盐矿/盐块（需 worldgen，成本中；更符合"粗盐提纯制取氯化钠"的原话）
- **电解的实现**：Create 无电 → 用**超高温（SUPERHEATED）+ 动力**当门槛（复用 Cannons 熔炼或新增"电解槽"方块，后者留到有验证需求时再做）
- **产物表达（关键决策）**：本批**建议全部物品化**，避免为气体引入流体物理子系统：
  - 氯气 → 石灰乳吸收 → **漂白粉**（次氯酸钙，固体，化学真实）
  - 氢气 → "加氢"：植物油 + 氢 → 硬化油/起酥油（接 Confectionery）；或压缩氢气瓶（物品）作 Cannons 推进剂
  - 烧碱 → 现有碱液的固体形态（可堆叠、可运输）
- **下游**：漂白粉 → 漂白浆 → 特种纸（接 06 F2 的"漂白"开放项）；硫（§5.1）+ 硝石 + 炭 → 火药线（Cannons 联动，作者视频已有预告）
- **气体形态**：若坚持真气体流体，需自定义 `FluidType`（MC 流体无浮力物理，气体只是"不可放置的流体/罐装"），工作量与风险显著上升 → **列为独立决策项**（§7）

### 5.5 横切一：化学品安全（P2，低成本）

- 生石灰/熟石灰/碱液/黑液：徒手接触 → 轻微伤害/DoT；副手持**防护手套**（皮革/橡胶）免疫
- 与 F3 污染深化合并为"化学品安全"机制包（同一套配置开关）
- 反馈来源：⑧；成本小、拟真收益高

### 5.6 横切二：染色批量路径（P2）

- 纸浆/精浆 + 染料 → 有色纸浆（染料 : 纸 = 1:4）→ 走既有成形/压制 → 彩色纸；手工"纸+染料"保持 1:1 但逐张合成 = 效率低
- 判据 4（批产优于手工）的正面例子；不做⑨的完整套娃（作者已示意过复杂）
- **汽鸣铁道颜色兼容**（⑬）与 `06 C1` 合并评估

### 5.7 横切三：配置化（P1，玩家点名 + 整合包刚需）

- 引入 `ModConfigSpec`，至少三类：

## 6. 明确不做 / 暂缓
