# 07 · 设计原则与产线蓝图

> **本文是设计母文档**（取代旧 `07-production-redesign.md`）：所有新内容的准入依据、产线结构的唯一权威描述。
> 配套文档：03（配方清单）、04（禁令判据，本文执行规则 C1 的展开）、06（发展建议/路线图）。
> 依赖前提：**机巧新生（Create Crafted Beginning，下称 CCB）是极其重要的前置/联动依赖**（2026-09-26 作者定调）。引入理由：它提供本模组一直缺失的三个坐标系——**气相（气体注册表/物流/压力）、冷相（冷却系统）、真正的化工设备（反应釜/分馏塔/注气室）**。

## 0. 一句话定位

**化工实用主义**：把现实工业的物料流翻译进 Create 的机械语言。造纸是旗舰线（当前内容），化学是骨架（长期方向）；一切内容服务于"可读的物料流"——**每条流有出处、有代价、有去向**。

## 1. 原则集

### 1.1 母原则（宪法级，不可违）

- **A1 主题**：化工实用主义。造纸为旗舰线而非边界；新线准入走本原则集。
- **A2 现实逻辑优先**：配方是现实工艺的翻译。产物的来源、过程、副产必须与现实一致或至少不冲突；**允许简化过程，不允许凭空造物**。
- **A3 物料守恒与出处**：进料决定出料；"谁变成谁"不能错；数值可简化，守恒关系不可破。（先例：否决"黑液提硫"——蒸煮配料无硫源；骨粉改回原版产量——不做无意义放大。）
- **A4 代价可见**：每条收益挂代价（环境/能耗/时间/物料），代价必须能被玩家感知。（先例：黑液污染 + 污染指示仪；浓缩液"处理即安全"。）

### 1.2 派生规则（生成内容时用）

- **B1 功能判据**：一物一功能；玩法功能相同即合并。（先例：钠/钾碱液合并为碱液。）
- **B2 密度判据**：注册前必须有 ≥2 条真实下游（含跨模组）。
- **B3 层级判据**：流体=功能类别（宽）；元素/纯度差异→物品层（固体）；**气体→CCB 气体系统**；温度/压力→工艺条件。
- **B4 无孤儿**：注册物皆有去向；"预留"允许但必须挂账编号（06 路线图）。
- **B5 机械优于手工**：工业路线相对手工必须有明确优势（产量/批量/自动化），但不做无意义放大。
- **B6 操作分类**：反应（盆/釜）、分离（分馏/过滤）、相变（冷/热/蒸发/结晶）、成形（辊/压/口）、物流（气罐/管道/带）——**不同操作不塞同一台机器**。CCB 接入后，"温度方向"与"压力"成为一等公民条件。
- **B7 消歧次序**：先问"这两条配方在现实里是不是同一个操作"。是 → 合并或阶梯化；不是 → 给它们不同的机器/操作或温度条件。**物料扣除（`neoforge:difference`）是补漏手段，不是首选。**

### 1.3 执行规则（决策与维护时用）

- **C1 禁令**：只禁"现实逻辑不成立"的直达配方；回收/再生/解包保留（展开见 04）。
- **C2 联动准入**：对方要么吃我们的中间产物、要么给我们的产物去向（双向性优先于单向索取）。
- **C3 依赖分层**：**核心线（纸/碱/黑液/糖）的可玩性不依赖可选模组**；扩展线（气体/酸/分馏/压力）依托 CCB，且必须 `whenModLoaded` 门控或明确声明为扩展玩法。
- **C4 三对齐**：源码=生成物=文档；改配方必跑 runData 并逐条核对。

### 1.4 冲突裁决顺序

**A2 现实 > A3 守恒 > A4/B4 代价与去向 > B6/B7 操作与体验 > 数值便利。**
数值方便不能压倒逻辑；逻辑不能压倒"能玩"（A4/B4 是底线门槛）。

## 2. 现状诊断（结构性问题，有证据）

| # | 问题 | 证据 |
|---|---|---|
| 1 | **工艺操作失序**：反应/相变/分离/粉碎全塞两台机器 | 碎浆机 6 职（制浆/糖浆/绞肉/粘土/沙/萤石）；混合机 12 职（苛化/浓缩/结晶/皂化/复分解…） |
| 2 | **温度单向**：只有常温/加热/超高温，"结晶"被迫写成加热 | 糖浆结晶、凝固只能借加热/水桶 |
| 3 | **同机同输入歧义** | 糖浆→糖 vs 糖浆→焦糖（已撤）；甘蔗同时在纸料/糖料标签 |
| 4 | **物料无分级**：一次纤维（木/竹）、农业副产（树皮/草秆）、经济作物（甘蔗）同处一个标签 | `create:pulpifiable` 15 成员；回收料（碎纸片）无身份 |
| 5 | **气相缺席**：酸碱盐缺一维，酸线卡死的真正原因 | 全实例无气体；CCB 补上这一维 |
| 6 | **中间物语义重复/悬空** | 4 条制浆变体输出全同；2 条精浆化学含义不明；粗纸零消耗；甘油/酵母×2 挂账 |
| 7 | **代价链不完整**：污染无治理；黑液回补 10% 象征性 | F3 长期缺口 |

## 3. CCB 接入面（调研摘要，2026-09-26）

### 3.1 气体系统
- 独立注册表 `createcraftedbeginning:gas`（**代码注册**；数据包只能加 tag，第三方用 `DeferredRegister` 或 KubeJS 注册气体）。
- 11 种气体：natural/ultrawarm/ethereal air（+energized 变体）、moist/spore/sculk air、steam、creative_air、empty。
- 配方字段：`gas_ingredients` / `gas_results`，单位 GU（1 atm 下 1 GU = 1 L），可选 `minimum_pressure` / `maximum_pressure`（Pa）。
- 物流：气密罐（多方块 2880 kL）/气罐（可附魔扩容）/气罐包（Curios）/抽屉（Functional Storage 兼容）/打包机（Create 包裹物流）/工厂仪表/移动结构接口。
- 压力：`P = amount × 100000 / volumeL`；来源=环境大气、气密泵/调压泵（旋转动力），>16 atm 破裂。
- **产气只有 4 种类型**：energization / dissipation / reactor_kettle / fractionation_tower。**蒸汽唯一来源 = 贴在 Create 锅炉上的 BoilerSteamOutlet（上限 5 atm）**，去向：引擎 workFactor 2.0（高压 20）、特斯拉涡轮 4.0/12.0、装备 handler、residue_generation 排放。

### 3.2 冷却系统
- `chilling`：**Create 风扇加工类型**（风扇 + 充能的 Breeze Cooler），1 物品→≤12 输出。
- `cooling`：Breeze Cooler 的"冷却燃料表"（雪 10t / 冰 200t / 浮冰 1800t / 蓝冰 16200t / 雪泥流体 160t…）。
- `chilled_mixing` / `chilled_compacting`：**Create 盆混合/压实的"冷冻条件版"**（盆下方必须是 CHILLED 的冷却器）——**第三方可直接写这种类型的配方**。
- Breeze Cooler：刷怪笼捕获旋风人获得；冷却时长即燃料（上限 72000t）。

### 3.3 化工机器
- `reactor_kettle`（反应釜）：物品/流体 + 气体输入；`temperature` 五档（superchilled/chilled/none/heated/superheated）+ `temperature_matching`；还能自动跑 Create mixing/酿造/无序合成。
- `fractionation_tower`（分馏塔）：按 `layer`(1–8) 分层出料（每层一件：物品/流体/气体），带温度条件；每层 9 物品槽 + 1 流体罐 + 1 气罐。
- `gas_injection`（注气室）：顶面接气，下方 2 格处理传送带/置物台物品（下方是盆则走流体注入）。
- **12 种自有配方类型全部可被第三方直接使用**（JSON/KubeJS schema 均已提供）。

### 3.4 风险
- CCB 有 **30 common + 25 client 个 mixin 注入 Create 内部**（`defaultRequire:1`），重灾区：Basin / Packager 家族 / LogisticsManager / FanProcessing / BoilerData / BeltMovementHandler / ManualApplicationRecipe。
- 与本模组现有 mixin（BanRecipes / BeltLowProcessing / AssemblyOperatorInject / SawInject）**无直接目标重叠**，但改盆、传送带、风扇、包装时要与 CCB 对齐验证。
- 数据侧现状：CCB 与本模组目前**零交互**（快照验证）。

## 4. 产线蓝图

图例：`[核心]` = 零模组依赖；`[扩展]` = 依赖 CCB（whenModLoaded）。

### 4.1 纸线 `[核心]`
```
原料分级（新）：主料=木屑(CDG)/竹/树苗；副产=树皮(FD)/草秆(FD)/甘蔗渣；回收料=碎纸片
常温制浆：4 主料 + 水1000 → Pulp 500（无黑液；前期/环保路径）
碱法蒸煮：4 主料 + 碱液1000 + 加热 → Pulp 1000 + 黑液250        ← 液体碱=现实白液
碱抽提精浆：Pulp1000 + 碱液 + 加热(+压力) → Fine Pulp 1000 + 黑液 ← 溶出木质素，必产黑液
成形：造纸框 + Pulp/FinePulp → 返还框 + 湿浆/精浆物品
压制：湿浆→粗纸；精浆物品→原版纸
回收线：粗纸/纸制品 →（粉碎）→ 碎纸片 → 回收浆(低产) → 回到成形
```
变更点：① 制浆精简为 2 条（见 §6-1）；② 精浆=碱抽提且**副产黑液**（修正现状"化学精浆不产黑液"的守恒漏洞）；③ 碎纸片来源需研究（§6-2）。

### 4.2 碱/石灰线 `[核心]`
```
草木灰(烧主料) → 灰汁(浸出) → 苛化(+生石灰) → 碱液 + 碳酸钙 → 煅烧 → 生石灰（闭环）
石灰乳(建材) = 熟石灰×2 + 沙×2 + 水250 → 500mB（已落地）
```
变更点：删"灰汁直接蒸煮/物品碱蒸煮"两条（§6-1）；灰汁唯一去向=苛化（语义更纯）。

### 4.3 黑液线 `[核心]` + `[扩展]` 增强
```
核心：黑液 →（加热浓缩）→ 浓缩黑液(安全形态) → 苛化 → 碱液(回补) + 碳酸钙
兜底：黑液 + 骨头 → 骨粉×3
增强：浓缩/分离走 CCB 分馏塔（多层：水回收 / 碱液 / 残渣）— 现实多效蒸发的对应
```

### 4.4 糖线 `[核心]`（阶梯化 + 消歧）
```
甘蔗渣(纸线副产/浸出副产) → 可制浆
糖原料 + 水 + 加热（混合机=浸出/熬煮）→ Syrup      ← 糖浆移出碎浆机（操作正确性）
Syrup →（冷却结晶）→ 糖 →（加热焦化）→ 焦糖        ← 阶梯；结晶用 CCB chilled_mixing
```
决策：糖浆从碎浆机迁至混合机（甘蔗歧义随机器分离消失）；结晶优先用 CCB 冷却（`chilled_mixing`）；焦糖恢复"由糖而来"的阶梯语义（04 的 caramel 禁令相应调整）。若 CCB 缺席：糖线降级为不可用（前置依赖线）。

### 4.5 化工/酸线 `[扩展]`
```
气体注册：rationality 名下气体（如 chlorine）走 CCB 气体注册表 + 气体 tag
漂白：纸浆/纸 + 注气（Cl₂）→ 漂白浆/特种纸（gas_injection）
高压反应：reactor_kettle 的温度+气体+压力条件承载蒸煮升级、苛化、复分解
蒸汽：Create 锅炉 → BoilerSteamOutlet → 蒸汽用于活性炭活化/蒸煮升级/特斯拉涡轮
酸线二期：待摸底 CCB brimstone（硫磺火流体，lava+energized_ultrawarm_air 制）能否作为硫源
```
约束（A3）：核心物料的来源不得脱离现实工艺；CCB 的"大气残渣"（空气→黏土/水等）只能作为**有出处的环境副产**接入，不得替代核心物料（如碱）。

### 4.6 建材线（作者设计中）
石灰乳已落地；"石灰涂层系统"由作者设计高级渲染（方块表面附着石灰色），数据侧由本模组提供涂层载体（BlockState 存储 + 涂覆/剥除）。纸筋灰撤出待斟酌。

### 4.7 副产与净化 `[核心]`
```
净化（F3）：优先**炭基吸附剂**（作者定调）：
  活性炭 = 木炭 + 蒸汽 + 高温（现实蒸汽活化；蒸汽来自 CCB 锅炉）→ 吸附剂
  用途：污染区块治理（消耗物料+时间，代价可见 A4）
其他副产：炭灰→吸附剂原料候选；甘油/酵母液体→有机线（06 F5）；煤矸石已定档（劣质燃料+石料）
```

## 6. 待决项

1. **制浆变体精简**（作者要求详解）：现状 4 条 → 建议 2 条（常温 500 + 碱液蒸煮 1000+黑液）。理由：三条碱法输出全同，成本上"物品碱=2 碱性物"严格最便宜，碱液路线隐含 4 草木灰、灰汁路线 6 草木灰——纯支配关系，两条贵的是 JEI 噪音且语义不真实（现实只有液体白液蒸煮）。删后碱线成为纸线必经上游（主题强化）。**配套增益**：碱法升级档用 CCB 压力——高压（≥2 atm）时碱液用量减半（"压力蒸煮提高碱液利用率"，现实依据充分），给碱经济第二条杠杆（第一条是苛化回补 10%）。
2. **碎纸片产出研究**（作者批准可做）：候选来源=粗纸粉碎 / 成形概率副产（FormingRecipe 已支持概率输出）/ 纸制品回收；需实测手感与产率后定稿。
3. **酸线二期**：先确认 CCB brimstone 能否作为硫源（其分馏塔产出=lava+ultrawarm_air，brimstone 本身由 lava+energized 空气制得）；再设计硫酸/硝酸与漂白线。
4. **F3 净化细节**：炭基吸附剂的作用范围（区块/半径）、消耗与时长、与污染指示仪的联动。
5. **有机线**（06 F5）：酵母液体×2 + 甘油的下游（酒/发酵/沼气）。
6. **制浆的"压力档"数值**：高压减碱的具体数值与设备门槛。

## 7. 维护规则

- 新增任何内容前，逐条过 §1 原则集；不满足 A2/A3 的提案直接否决。
- 依赖 CCB 的配方必须 `whenModLoaded(Create Crafted Beginning)`；核心线（A/B/C/D 类）保持无它可玩。
- 改配方后跑 `runData`，同步 03 配方表与本文 §4 蓝图（C4 三对齐）。
